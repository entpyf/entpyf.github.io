# 光动力治疗计算器

Photodynamic Therapy Calculator

## 简介

这是一个用于光动力治疗（PDT）的在线计算工具，包含以下功能：

- **功率计算** - 根据能量密度、光纤长度、照射时间和半径计算输出功率及功率密度
- **能量密度计算** - 根据输出功率、光纤长度、照射时间和半径计算能量密度
- **儿童患者半径预测** - 基于儿童年龄预测照射半径（基于51例儿童数据的线性回归模型）
